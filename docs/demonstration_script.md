# MindSync AI – System Demonstration Script

This script guide details the chronological user actions and corresponding feature validations to demonstrate during a 10-minute viva session.

---

## Part 1: Authentication & Onboarding (2 Minutes)
1. **Launch App**: Open the emulator. The app displays the **Splash Screen** and evaluates local session states before loading the onboarding carousel slides.
2. **Register**: Click **Sign Up**, fill in your email, set a password, and tap register. The system validates inputs using client-side checks and calls Firebase Authentication.
3. **Login**: Go to the login screen, enter your credentials, and click **Login**. The client retrieves the Firebase ID Token and redirects to the main layout dashboard.

---

## Part 2: Dashboard Overview & Weather (2 Minutes)
1. **Dashboard Home**: Explain the cards structure. The screen watches `dashboardDataProvider` to display the overall wellness score and burnout risk levels.
2. **Weather Widget**: Point to the weather widget. It calls local location APIs to adapt wellness recommendations to the local climate.

---

## Part 3: Mood Logging & Analytics (2 Minutes)
1. **Log Mood**: Tap the floating action button or select the **Mood** tab. Drag sliders to log today's metrics: mood score, stress level, sleep hours, water intake, steps, and exercise minutes. Click **Save**.
2. **Local Cache check**: Note that the log is immediately visible in the history list. The UI updates instantly because the repository commits to the local Hive database first before syncing in the background.

---

## Part 4: AI Chat & Recommendations (2 Minutes)
1. **Habit Recommendations**: Click the **Recommendations** card. Note that it displays three advice items generated by the ML pipeline and explained by SHAP values.
2. **Wellness Coach Chat**: Navigate to the **AI Chat** tab. Type a message (e.g. *"I am feeling exhausted from code debugging today"*). The chat orchestrator sanitizes the inputs, queries the Gemini API, and appends a medical disclaimer to the supportive response.

---

## Part 5: Reports & PDF Exporter (1 Minute)
1. **Reports View**: Navigate to the **Reports** tab. The dashboard displays fl_chart graphs showing burnout risks, mood trends, and stress curves.
2. **PDF Backup**: Go to **Settings** -> **Data Management** and click **Export PDF** (or **Export JSON**). A download confirmation is shown, and the backup file is saved to the local directory.

---

## Part 6: Offline Mode Simulation (1 Minute)
1. **Disconnect internet**: Disable Wi-Fi. The dashboard displays the orange warning banner: *"You are offline. Running in local cache mode."*
2. **Log offline**: Go to the Mood log and enter another journal entry. Note that it saves locally. Reconnect Wi-Fi and verify that the sync engine automatically uploads the pending queue to Firestore.
