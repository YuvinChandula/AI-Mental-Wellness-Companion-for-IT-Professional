Industry Context & Motivation

The IT Developer Burnout Crisis

⚠️ High Cognitive Fatigue
  • High-pressure sprint cycles, tight release schedules, and constant debugging.
  • Prolonged screen exposure leading to sleep disturbance and physical exhaustion.
  • 60%+ of software engineers report experiencing severe burnout during their career.
⚡ Limitations of Existing Solutions
  • Generic fitness apps track steps but ignore cognitive workload & stress.
  • Siloed logs: Sleep, mood, hydration, and steps are never connected.
  • Static push notifications cause alert fatigue and are quickly disabled.
💡 The MindSync AI Solution

A unified mobile platform that correlates physical metrics (sleep, steps, hydration) with psychological indicators (mood ratings, stress logs) using machine learning to deliver predictive burnout warnings and transparent habit advice.

Project Scope

Aim & Key Technical Objectives

🎯 Overall Project Aim

To design, implement, and validate an offline-first mobile application that accurately predicts burnout risks for software engineers, explains contributing drivers, and delivers adaptive AI coaching.

1. Responsive Mobile App

Build a Material 3 mobile application using Flutter, Riverpod, and fl_chart for cross-platform telemetry visualisations.

2. Async Backend API

Construct a FastAPI microservices backend capable of delivering sub-22ms machine learning predictions.

3. Explainable ML Engine

Train a Random Forest model with SHAP tree interpretability to explain specific burnout factors.

4. Offline Resilience

Implement local Hive storage and an automatic cloud sync queue observer for seamless offline operation.

Predictive AI

Machine Learning Pipeline & SHAP XAI

🌲 Random Forest Model
  • Selected for superior performance on tabular wellness features.
  • Input vector: Sleep hours, Screen time, Mood score, Stress level, Water intake, Steps.
  • Output classes: Low Risk, Moderate Risk, High Risk.
  • Achieved 93.3% accuracy on cross-validation sets.
🔍 Explainable AI (SHAP)
  • Calculates SHAP values to explain specific tree decision weights.
  • Prevents "black-box AI" by outputting top 3 contributing factors.
  • Example output: "Risk driven by <5.5 hrs sleep and >10 hrs work time."

Generative AI

Gemini LLM Orchestration & Reliability

💬 Gemini 1.5 Flash Integration
  • Generates tailored developer habit recommendations.
  • Powers the interactive AI Wellness Coach chat session.
  • Analyses raw text journal entries for emotional sentiment.
🛡️ Resilience & Fail-Safe Architecture
  • Exponential Backoff: Retries failed API calls safely.
  • Rule-Based Fallback Engine: Instantly returns static rule-based summaries if Gemini API is unreachable.
  • Prompt Sanitization: Prevents prompt injection attacks.
  • Medical Disclaimer: Appended to all health guidance outputs.

Data Resilience

Offline-First Architecture & Sync Engine

💾 Synchronous Hive Local DB
  • Every user log commits immediately to high-speed Hive key-value boxes.
  • Guarantees 100% app usability in offline environments.
  • Instant UI rendering without waiting for network responses.
🔄 Connectivity Observer & Queue
  • `connectivity_plus` actively monitors network status changes.
  • Queues un-synced entries locally with timestamps.
  • Triggers automatic background sync to Cloud Firestore when internet restores.

Cybersecurity & QA

Security Hardening & Quality Assurance

🔐 Auth Security

Firebase JWT ID Token validation in backend middleware. Granular Firestore Security Rules isolate user data collections.

🛡️ Endpoint Protection

OWASP security headers (HSTS, CSP, X-Frame-Options), memory rate limiters, and strict Pydantic input sanitization.

🧪 Automated Testing

Pytest backend test suite for API endpoints and ML models. Flutter Test widget & provider verification suite.

✅ Regulatory Compliance & Health Disclaimers

Applies GDPR data export rights (PDF/JSON data export) and displays clear medical disclaimers declaring the app as a wellness companion rather than a clinical diagnostic tool.
